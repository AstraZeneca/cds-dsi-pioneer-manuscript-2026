# Contributing to PIONEER

Thank you for your interest in PIONEER. This document outlines the contribution process.

## Contribution Policy

This repository is maintained by the Clinical Data Science team at AstraZeneca. We welcome contributions from AstraZeneca colleagues via internal pull requests.

External contributions are accepted via GitHub pull requests, subject to the guidelines below.

## How to Contribute

1. **Report issues:** Open a GitHub issue describing the bug or feature request.
2. **Submit changes:** Fork the repository, create a feature branch, and submit a pull request.
3. **Code review:** All pull requests require review from at least one maintainer before merging.

## Pull Request Guidelines

- Keep changes focused and atomic — one logical change per PR.
- Include a clear description of what changed and why.
- Ensure the `{targets}` pipeline runs without errors.
- Follow existing code style (enforced by `.lintr` for R code).

## Code of Conduct

Contributors are expected to follow the [AstraZeneca Open Source Code of Conduct](https://github.com/AstraZeneca/.github/blob/main/CODE_OF_CONDUCT.md).

## Questions

For questions about contributing, contact the maintainers listed in [AUTHORS.md](AUTHORS.md).
