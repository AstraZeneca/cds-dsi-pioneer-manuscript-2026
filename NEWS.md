# NEWS

## v1.0.0 (2026-08-13)

Initial public release accompanying the manuscript submission.

### Features

- Bayesian joint model coupling mechanistic tumour growth to time-to-event endpoints
- Two-component state-space submodel for longitudinal SLD dynamics
- Multistate proportional-hazard submodel for competing clinical events
- Dynamic prediction framework for immature trial data
- Leave-future-out cross-validation implementation
- ES-SCLC case study with Project Data Sphere data (N = 497)

### Infrastructure

- Reproducible `{targets}` pipeline
- Stan model with modular parameter components
- `{renv}` lockfile for dependency management
- Quarto-based publication output
