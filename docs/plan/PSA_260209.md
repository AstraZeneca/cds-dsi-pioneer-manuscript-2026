**Date:** 2026-02-09
**Author:** Claude Code

## Executive Summary

This document presents a comprehensive plan to adapt the PIONEER tumor dynamics model from solid tumors (SLD-based) to metastatic castration-resistant prostate cancer (mCRPC) using PSA as the primary biomarker. Key enhancements include:

1. **Latent tumor burden model** with modality-specific observation equations
2. **Multi-biomarker support** for PSA, LDH, ALP, ctDNA, and future markers
3. **Multi-state hazard model** (illness-death) replacing the current other-events module
4. **PCWG3-compliant progression criteria** replacing RECIST categories

---

## 1. Problem Statement

### 1.1 Original Problem

> The current PIONEER model comprises two parts:
>
> 1. **Mechanistic tumor growth module** (tr, frac, init modules) from which we calculate RECIST categories and determine PFS-violating events
> 2. **Proportional hazard module** (other-events) where covariates and tumor-derived covariates contribute to hazard, then probability of survival, then log-odds, finally Bernoulli trial which determines when a PFS-violating event occurs
>
> The model chooses the earliest PFS-violating event. The entire model is built on a hierarchical Bayesian framework, so PFS is computed per posterior sample.
>
> **Challenge:** Convert this model to work with metastatic prostate cancer where we do not have tumor size (SLD) measurements, instead we have Prostate Specific Antigen (PSA) measurements at baseline and various time intervals.

### 1.2 Mathematical Formulation

**Current SLD Model:**

```
SLD(t) = SLD_base × α × e^(−d×t) + SLD_base × (1−α) × e^(g×t)
```

Where:
- α ∈ (0,1) = sensitive tumor fraction
- d > 0 = decrease rate (treatment effect)
- g > 0 = growth rate (resistance)

**Initial PSA Formulation:**

```
PSA(t) = ρₛ × SLD_base × α × e^(−d×t) + ρᵣ × SLD_base × (1−α) × e^(g×t)
```

Where ρₛ and ρᵣ are PSA release rates from sensitive and resistant tumor cells.

**Identifiability Problem:** From PSA observations alone, we cannot separately identify (ρₛ × SLD_base × α) and (ρᵣ × SLD_base × (1−α)).

### 1.3 Extended Questions (from 2026-02-09 discussion)

1. **Latent Burden:** If we only have PSA observations, how do we obtain the latent tumor burden to pass to the hazard module?

2. **Multi-Biomarker:** If additional lab results become available (LDH, ALP, ctDNA), can we add parallel observation equations?

3. **PSA and Death:** Is PSA more directly prognostic for death than SLD? Should the hazard model structure change?

4. **Multi-State Model:** Should we replace the current competing-risks framework with an illness-death multi-state model?

5. **PCWG3 Categories:** What are the PSA equivalents of RECIST categories (CR, PR, SD, PD)?

## 2. Proposed Solution: Latent Tumor Burden Model

### 2.1 Core Architecture

The key insight is to separate the **latent tumor state** from the **observation model**:

```
┌─────────────────────────────────────────────────────────────────────┐
│                 SINGLE LATENT TUMOR STATE                           │
│                                                                     │
│     Sensitive: φ × e^(−d×t)      Resistant: (1−φ) × e^(g×t)        │
│                                                                     │
│     True Burden: B(t) = φ × e^(−d×t) + (1−φ) × e^(g×t)             │
└─────────────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        ▼                     ▼                     ▼
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│  SLD (λ=1)    │     │  PSA (λ_PSA)  │     │  LDH (λ_LDH)  │
│  Observation  │     │  Observation  │     │  Observation  │
└───────────────┘     └───────────────┘     └───────────────┘
```

### 2.2 Latent State-Space Model

**State Variables:**

```
xₛ(t) = log(sensitive burden)
xᵧ(t) = log(resistant burden)
```

**Initial Conditions (at t=0):**

```
xₛ(0) = log(φ)
xᵧ(0) = log(1 − φ)
```

Where φ ∈ (0,1) is the sensitive fraction of total tumor burden at baseline.

**Dynamics:**

```
xₛ(t + Δt) = xₛ(t) − d × Δt
xᵧ(t + Δt) = xᵧ(t) + g × Δt
```

**Normalized Total Burden:**

```
B(t) = e^(xₛ(t)) + e^(xᵧ(t)) = φ × e^(−d×t) + (1−φ) × e^(g×t)
```

### 2.3 Observation Models

#### 2.3.1 SLD Observation (Solid Tumors)

SLD is directly proportional to tumor burden:

```
log(SLD(t) / SLD_base) ~ Normal(log(B(t)), σ²_SLD)
```

#### 2.3.2 PSA Observation (Prostate Cancer)

PSA reflects tumor burden weighted by differential production rates:

```
PSA(t) ∝ φ × e^(−d×t) + λ × (1−φ) × e^(g×t)
```

Where λ = ρ_resistant / ρ_sensitive is the relative PSA production rate.

**Normalized PSA:**

```
PSA(t)              φ × e^(−d×t) + λ × (1−φ) × e^(g×t)
────────────── = ─────────────────────────────────────── = B_PSA(t)
PSA_base                    φ + λ × (1−φ)
```

**Observation Model:**

```
log(PSA(t) / PSA_base) ~ Normal(log(B_PSA(t)), σ²_PSA)
```

### 2.4 The λ Parameter

| Value | Interpretation |
|-------|----------------|
| λ = 1 | Equal PSA production; B_PSA(t) = B(t) |
| λ > 1 | Resistant cells produce more PSA; PSA rises faster than tumor grows |
| λ < 1 | Resistant cells produce less PSA; PSA underestimates resistant burden |

**Identifiability:**

| Data Available | What's Identifiable |
|----------------|---------------------|
| SLD only | B(t), φ, d, g |
| PSA only, λ=1 | B(t) = B_PSA(t), φ = α_PSA, d, g |
| PSA only, λ≠1 | B_PSA(t), α_PSA, d, g (NOT φ, λ separately) |
| Both PSA + SLD | B(t), B_PSA(t), φ, λ, d, g |

**PSA-Weighted Sensitive Fraction:**

```
              φ
α_PSA = ─────────────────
        φ + λ × (1 − φ)
```

**Inverse Relationship:**

```
        α_PSA × λ
φ = ─────────────────────────
    α_PSA × λ + (1 − α_PSA)
```

## 3. Multi-Biomarker Extension

### 3.1 General Framework

For any biomarker k with production ratio λₖ:

```
Yₖ(t)       φ × e^(−d×t) + λₖ × (1−φ) × e^(g×t)
──────── = ───────────────────────────────────── = Bₖ(t)
Yₖ_base              φ + λₖ × (1−φ)
```

```
log(Yₖ(t) / Yₖ_base) ~ Normal(log(Bₖ(t)), σ²ₖ)
```

### 3.2 Prostate Cancer Biomarkers

| Biomarker | λ Parameter | Clinical Relevance |
|-----------|-------------|-------------------|
| PSA | λ_PSA | Primary marker, tumor activity |
| LDH | λ_LDH | Tumor burden, tissue damage |
| ALP | λ_ALP | Bone disease activity |
| ctDNA | λ_ctDNA | Circulating tumor DNA |

### 3.3 Architecture Diagram

```
┌─────────────────────────────────────────────────────────────────────┐
│                 SINGLE LATENT TUMOR STATE                           │
│                                                                     │
│     Parameters: φ, d, g (SHARED across all biomarkers)             │
│                                                                     │
│     True Burden: B(t) = φ × e^(−d×t) + (1−φ) × e^(g×t)             │
└─────────────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        ▼                     ▼                     ▼
┌───────────────┐     ┌───────────────┐     ┌───────────────┐
│  PSA (λ_PSA)  │     │  LDH (λ_LDH)  │     │  ALP (λ_ALP)  │
│  B_PSA(t)     │     │  B_LDH(t)     │     │  B_ALP(t)     │

└───────────────┘     └───────────────┘     └───────────────┘
```

## 4. PCWG3 vs RECIST: Response Categories

### 4.1 Comparison Table

| RECIST Category | SLD Criterion | PCWG3/PSA Analog | PSA Criterion |
|-----------------|---------------|------------------|---------------|
| **CR** | SLD = 0 | **PSA Undetectable** | PSA < 0.1 ng/mL |
| **PR** | ≥30% decrease from baseline | **PSA50** | ≥50% decrease from baseline |
| **SD** | Neither PR nor PD | **PSA Stable** | Neither PSA50 nor PSA-PD |
| **PD** | ≥20% increase from nadir AND ≥5mm | **PSA-PD** | ≥25% AND ≥2 ng/mL from nadir (confirmed) |

### 4.2 PCWG3 PSA Progression Criteria (Scher et al. 2016)

**Scenario A: After PSA Decline from Baseline**

```
PSA-PD = TRUE if ALL of:
    • (PSA − nadir) / nadir ≥ 0.25
    • PSA − nadir ≥ 2 ng/mL
    • Confirmed by second value ≥ 3 weeks later
```

**Scenario B: No PSA Decline from Baseline**

```
PSA-PD = TRUE if ALL of:
    • t > 12 weeks
    • (PSA − baseline) / baseline ≥ 0.25
    • PSA − baseline ≥ 2 ng/mL
    • Confirmed by second value ≥ 3 weeks later
```

### 4.3 Key Differences

| Aspect | RECIST | PCWG3 PSA |
|--------|--------|-----------|
| **Confirmation** | Not always required | Required (≥3 weeks) |
| **Early protection** | None | No PD before 12 weeks if no decline |
| **Absolute threshold** | 5mm | 2 ng/mL |
| **Reference** | Nadir for PD, baseline for PR | Nadir (after decline) or baseline |

## 5. PSA and Death: Clinical Relationship

### 5.1 Why PSA May Be More Prognostic for Death

| Aspect | SLD (RECIST) | PSA |
|--------|--------------|-----|
| **Coverage** | Up to 5 target lesions | Total tumor activity from ALL sites |
| **Bone metastases** | Often not measurable | Well reflected |
| **Micrometastases** | Not captured | Contributes to PSA |
| **Measurement frequency** | Every 9-12 weeks | Every 3-4 weeks |

### 5.2 PSA Kinetics as Prognostic Markers

| PSA Metric | Prognostic Value | Evidence |
|------------|------------------|----------|
| PSA doubling time | < 3 months = poor prognosis | Multiple studies |
| PSA50 response | Correlates with OS | Phase 3 trials |
| PSA nadir | Deeper = better OS | Abiraterone, Enzalutamide |
| PSA velocity | Rising = higher death risk | PCWG3 |

### 5.3 Complete Covariate Specification: Longitudinal → Hazard Model

This section specifies **all covariates** that flow from the tumor dynamics module to the multi-state hazard model.

#### 5.3.1 Primary Tumor Burden Covariate (Time-Varying)

The burden covariate depends on available data and λ setting:

| Data Available | λ Setting | Burden Covariate | Formula |
|----------------|-----------|------------------|---------|
| **SLD only** | N/A | True burden B(t) | φ × e^(−d×t) + (1−φ) × e^(g×t) |
| **PSA only** | λ = 1 | B_PSA(t) = B(t) | φ × e^(−d×t) + (1−φ) × e^(g×t) |
| **PSA only** | λ ≠ 1 | B_PSA(t) | [φ × e^(−d×t) + λ×(1−φ) × e^(g×t)] / [φ + λ×(1−φ)] |
| **Both SLD + PSA** | Estimated | True burden B(t) | φ × e^(−d×t) + (1−φ) × e^(g×t) |

**Key insight:** When only PSA is observed and λ ≠ 1, we cannot estimate true tumor burden B(t). We use B_PSA(t) (PSA-represented burden) as the covariate instead. This is still clinically meaningful as it reflects what PSA tells us about disease activity.

#### 5.3.2 Core Time-Varying Covariates (from Current PIONEER)

| Covariate | Symbol | Time Nature | Description |
|-----------|--------|-------------|-------------|
| Log burden | log(B(t)) or log(B_PSA(t)) | Time-varying | Current tumor/PSA burden |
| Log decrease rate | log(d) | Time-invariant* | Treatment sensitivity |
| Log growth rate | log(g) | Time-invariant* | Resistance/progression rate |
| Burden velocity | d/dt log(B(t)) | Time-varying | Rate of change in burden |

*Can be time-varying if AR(1) process noise is enabled (`enable_patient_process_noise_tr`)

#### 5.3.3 Additional PSA-Derived Covariates (New for Prostate Cancer)

| Covariate | Formula | Time Nature | Interpretation |
|-----------|---------|-------------|----------------|
| PSA nadir | min(B_PSA(s)) for s ≤ t | Time-varying | Best response achieved so far |
| Time to nadir | argmin(B_PSA(s)) for s ≤ t | Time-varying | When best response occurred |
| Nadir ratio | B_PSA(t) / nadir(t) | Time-varying | Current burden relative to best response |

**Note:** PSA doubling time (log(2)/g) and PSA half-life (log(2)/d) are sometimes reported clinically, but these are just monotonic transformations of log(g) and log(d) respectively. Since log(g) and log(d) are already included as covariates, adding doubling time or half-life would be redundant.

#### 5.3.4 Summary Table: All Covariates for Hazard Model

| # | Covariate | Source | Time Nature | Used In Transitions |
|---|-----------|--------|-------------|---------------------|
| 1 | log(B(t)) or log(B_PSA(t)) | Longitudinal model | Time-varying | 0→1, 0→2 |
| 2 | log(d) | Longitudinal model | Time-invariant* | 0→1, 0→2, 1→2 |
| 3 | log(g) | Longitudinal model | Time-invariant* | 0→1, 0→2, 1→2 |
| 4 | Velocity d/dt log(B) | Longitudinal model | Time-varying | 0→1, 0→2 |
| 5 | PSA nadir | Derived from B_PSA | Time-varying | 1→2 |
| 6 | Time to nadir | Derived from B_PSA | Time-varying | 1→2 |
| 7 | Nadir ratio | Derived from B_PSA | Time-varying | 0→1, 0→2 |

Plus **non-tumor covariates** (time-invariant patient characteristics): age, ECOG, hemoglobin, albumin, LDH, ALP, prior therapies, etc.

## 6. Multi-State Hazard Model (Illness-Death)

### 6.1 Motivation

The current PIONEER model uses a competing-risks framework where progression and death are conflated. A **multi-state illness-death model** is more clinically realistic:

- Patients who progress may have different death hazard than those who don't
- Post-progression survival can be explicitly modeled
- Clinical progression diagnosis can be directly incorporated

### 6.2 State Diagram

```
                    ┌─────────────────┐
                    │  No Progression │
                    │    (State 0)    │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
          λ₀₁(t)             │          λ₀₂(t)
              │              │              │
              ▼              │              ▼
    ┌─────────────────┐      │    ┌─────────────────┐
    │   Progressed    │      │    │      Dead       │
    │    (State 1)    │      │    │    (State 2)    │
    └────────┬────────┘      │    │   (absorbing)   │
             │               │    └─────────────────┘
             │          λ₁₂(s)            ▲
             │               │            │
             └───────────────┴────────────┘
```

**Three Transitions:**
- λ₀₁(t): No Progression → Progression
- λ₀₂(t): No Progression → Death (without progression)
- λ₁₂(s): Progression → Death (post-progression, clock reset)

### 6.3 PSA Role in Each Transition

| Transition | PSA Role | Primary Drivers |
|------------|----------|-----------------|
| **0→1 (Progression)** | ★★★★★ PRIMARY | PSA dynamics define PCWG3 progression |
| **0→2 (Death w/o progression)** | ★★★ MODERATE | Clinical factors dominate (ECOG, comorbidities) |
| **1→2 (Post-progression death)** | ★★★★ IMPORTANT | PSA at progression, nadir, history |

### 6.4 Transition Hazard Models

#### Transition 0→1: Progression

**Option A: Deterministic (from PCWG3)**

```
T₀₁ = min{t : PCWG3_criteria_met(PSA(t), PSA_base, nadir(t), t)}
```

**Option B: Stochastic Hazard**

```
λ₀₁(t) = λ₀₁_base(t) × exp(β₁ × log(B_PSA(t)) + β₂ × velocity(t))
```

#### Transition 0→2: Death Without Progression

```
λ₀₂(t) = λ₀₂_base(t) × exp(
    γ₁ × log(B_PSA(t)) + γ₂ × velocity(t)
  + γ₃ × age + γ₄ × ECOG
  + γ₅ × hemoglobin + γ₆ × albumin
  + γ₇ × LDH + γ₈ × ALP
)
```

#### Transition 1→2: Post-Progression Death

```
λ₁₂(s) = λ₁₂_base(s) × exp(
    δ₁ × log(PSA_at_progression)
  + δ₂ × log(PSA_nadir)
  + δ₃ × log(T₀₁)
  + δ₄ × age + δ₅ × ECOG_at_progression
)
```

Where s = t − T₀₁ is time since progression (clock reset).

### 6.5 Information Flow

```
┌─────────────────────────────────────────────────────────────────────┐
│                      PSA DYNAMICS MODULE                            │
│                      (tr, frac, init)                               │
│                                                                     │
│  Outputs:                                                           │
│  - B_PSA(t): PSA-represented tumor burden over time                │
│  - d, g: Decrease and growth rates                                 │
│  - T₀₁: Progression time (from PCWG3 criteria)                     │
│  - Derived: nadir, time-to-nadir, nadir ratio, velocity            │
│                                                                     │
│  PRIMARY ROLE: Determine transition 0→1 (Progression)              │
└─────────────────────────────────────────────────────────────────────┘
                              │
                              │ Provides covariates
                              ▼
┌─────────────────────────────────────────────────────────────────────┐
│                 MULTI-STATE HAZARD MODULE                           │
│                 (replaces other_events)                             │
│                                                                     │
│  Transition 0→1: Deterministic from PSA dynamics OR hazard model   │
│  Transition 0→2: Hazard with PSA covariates + clinical factors     │
│  Transition 1→2: Hazard with post-progression PSA + clinical       │
│                                                                     │
│  Outputs:                                                           │
│  - T₀₂: Time to death without progression                          │
│  - T₁₂: Post-progression survival time                             │
│  - OS = min(T₀₂, T₀₁ + T₁₂)                                        │
└─────────────────────────────────────────────────────────────────────┘
```

## 7. Clinical Endpoints

### 7.1 Endpoint Comparison

| Endpoint | Solid Tumors (RECIST) | Prostate Cancer (PCWG3) |
|----------|----------------------|-------------------------|
| **Response Rate** | ORR = CR + PR | PSA50 rate, PSA90 rate |
| **Progression** | RECIST PD | PSA-PD (confirmed) |

| **rPFS** | N/A | Radiographic PFS (if imaging) |
| **OS** | Time to death | Time to death |

### 7.2 Composite Endpoints in Multi-State Model

**Progression-Free Survival:**

```
PFS = min(T₀₁, T₀₂)
```

**Overall Survival:**

```
        ┌ T₀₂           if death without progression
OS =    │
        └ T₀₁ + T₁₂     if death after progression
```

**Post-Progression Survival:**

```
PPS = T₁₂  given that T₀₁ < T₀₂
```

## 8. Implementation Phases

### Phase 1: PSA-Only Model (λ = 1)

**Scope:**
- Replace SLD with PSA throughout
- Implement PCWG3 progression criteria
- Keep current hazard model structure (single other-events)
- Assume λ = 1 (mathematically identical to current model)

**Deliverable:** Working PSA model for prostate cancer

**Changes:**
- Observation model: `log(PSA/PSA_base) ~ Normal(log(B(t)), σ)`
- Generated quantities: PCWG3 categories instead of RECIST
- Variable renaming: `log_sld` → `log_burden` or `log_psa`

### Phase 2: Multi-State Hazard Model

**Scope:**
- Replace other-events with illness-death model
- Three transitions: 0→1, 0→2, 1→2
- PSA dynamics primarily drive 0→1
- Death hazards (0→2, 1→2) use PSA covariates + clinical factors

**Deliverable:** Multi-state model with explicit progression and death transitions

**Changes:**
- New module: `multi_state_hazard/` replacing `other_events/`
- Likelihood: Multi-state survival likelihood
- Generated quantities: PFS, OS, PPS as separate outputs

### Phase 3: Hierarchical λ Parameter

**Scope:**
- Add λ as hierarchical parameter
- Allows differential PSA production
- Use informative prior centered at λ = 1

**Deliverable:** More flexible PSA model

**Changes:**
- New parameter: `lambda_psa` with prior `log(λ) ~ Normal(0, 0.5)`
- Observation model: `log(PSA/PSA_base) ~ Normal(log(B_PSA(t)), σ)`

### Phase 4: Multi-Biomarker Support

**Scope:**
- Support multiple biomarkers (PSA, LDH, ALP, ctDNA)
- Each biomarker has own λ and σ
- Shared latent tumor dynamics

**Deliverable:** Unified multi-modal model

**Changes:**
- Array of λ parameters: `lambda[n_biomarkers]`
- Multiple observation likelihoods
- Ragged data structure for different observation schedules

### Phase 5: Combined SLD + PSA (Future)

**Scope:**
- Support datasets with both imaging and PSA
- Identify true φ and λ from combined data
- Use true B(t) in hazard model

**Deliverable:** Fully unified model for any biomarker combination

## 9. Stan Implementation Sketch

### 9.1 Latent State Computation

```stan
// Shared across all biomarkers
for (i in 1:n_patients) {
  for (t in 1:max_t) {
    x_s[i,t] = log_phi[i] - d[i] * t;
    x_g[i,t] = log1m_phi[i] + g[i] * t;

    // True burden
    log_B[i,t] = log_sum_exp(x_s[i,t], x_g[i,t]);

    // PSA-weighted burden (if lambda != 1)
    log_B_PSA[i,t] = log_sum_exp(x_s[i,t], log(lambda) + x_g[i,t])
                   - log_sum_exp(x_s[i,1], log(lambda) + x_g[i,1]);
  }
}
```

### 9.2 Multi-Biomarker Observation Model

```stan
// For each biomarker k
for (k in 1:n_biomarkers) {
  for (j in 1:n_obs[k]) {
    int i = patient_idx[k, j];
    int t = time_idx[k, j];

    real log_B_k = log_sum_exp(x_s[i,t], log(lambda[k]) + x_g[i,t])
                 - log_sum_exp(x_s[i,1], log(lambda[k]) + x_g[i,1]);

    log_y_normalized[k, j] ~ normal(log_B_k, sigma[k]);
  }
}
```

### 9.3 PCWG3 Progression Detection

```stan
// In generated quantities
int psa_progression_week[n_patients];

for (i in 1:n_patients) {
  psa_progression_week[i] = -1;  // No progression
  real nadir = 1.0;
  int pending_pd_week = -1;

  for (t in 2:max_t) {
    real psa_t = exp(log_B_PSA[i,t]) * psa_base[i];
    nadir = fmin(nadir, exp(log_B_PSA[i,t]));
    real nadir_psa = nadir * psa_base[i];

    // Check PCWG3 criteria
    real pct_increase = (psa_t - nadir_psa) / nadir_psa;
    real abs_increase = psa_t - nadir_psa;

    int meets_criteria = (pct_increase >= 0.25) && (abs_increase >= 2.0);

    if (meets_criteria) {
      if (pending_pd_week > 0 && (t - pending_pd_week) >= 3) {
        // Confirmed progression
        psa_progression_week[i] = pending_pd_week;
        break;
      } else if (pending_pd_week < 0) {
        pending_pd_week = t;
      }
    }
  }
}
```

### 9.4 Multi-State Likelihood (Sketch)

```stan
// Multi-state hazard model
for (i in 1:n_patients) {
  // Transition 0→1 (if progression observed before death/censoring)
  if (progressed[i]) {
    target += log_hazard_01[i, t_progression[i]];
    // Survived transitions 0→1 and 0→2 until progression
    for (t in 1:(t_progression[i]-1)) {
      target += log1m_exp(log_hazard_01[i,t]) + log1m_exp(log_hazard_02[i,t]);
    }
  }

  // Transition 0→2 (if death without progression)
  if (died_without_progression[i]) {
    target += log_hazard_02[i, t_death[i]];
    // Survived both transitions until death
    for (t in 1:(t_death[i]-1)) {
      target += log1m_exp(log_hazard_01[i,t]) + log1m_exp(log_hazard_02[i,t]);
    }
  }

  // Transition 1→2 (if death after progression)
  if (progressed[i] && died[i]) {
    int s = t_death[i] - t_progression[i];  // Time since progression
    target += log_hazard_12[i, s];
    for (u in 1:(s-1)) {
      target += log1m_exp(log_hazard_12[i,u]);
    }
  }
}
```

## 10. Summary

### 10.1 Key Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Latent state | Normalized burden B(t) | Agnostic to observation modality |
| Phase 1 λ | Fix at 1 | Identifiable, minimal changes |
| Progression | PCWG3 criteria | Clinical standard for prostate cancer |
| Hazard model | Multi-state (illness-death) | Separates progression from death |
| PSA role | Primary for progression, covariate for death | Matches clinical evidence |

### 10.2 Advantages

1. **Unified framework**: Same latent dynamics, different observation models
2. **Future-proof**: Easy to add new biomarkers or imaging
3. **Clinically meaningful**: Multi-state model captures disease course
4. **Identifiable**: Clear separation of what can/cannot be estimated
5. **Backward compatible**: Phase 1 is mathematically identical to current model

### 10.3 Open Questions

1. Should λ vary by patient (hierarchical) or be population-level?
2. Should 0→1 transition be deterministic (PCWG3) or stochastic?
3. How to handle radiographic progression (rPFS) in addition to PSA-PFS?
4. Should post-progression hazard use clock-reset or clock-forward time?
