# Simple Survival Website Section — Design Spec

**Date:** 2026-04-14  
**Scope:** Add an "OS Survival Only Model" section to the Pioneer Quarto website showing
Week-13 landmark OS results for the `re_arm` variant.

---

## Goal

Surface the `simple_survival_*_re_arm` pipeline results on the website in a dedicated
section parallel to "Full Model". The page shows OS KM curves and quantile estimates only —
no PFS, no burden endpoints, no biomarker dynamics.

## 2. Store Configuration (`r/pioneer/target_stores.R`)

Add one new variable:

```r
simple_survival_store <- file.path(
  analysis_results_path, "pioneer",
  Sys.getenv("TAR_SIMPLE_SURVIVAL_RUN", "simple-survival"), "_targets"
)
```

Uses `TAR_SIMPLE_SURVIVAL_RUN` env var, defaulting to `"simple-survival"`. The `_setup.R`
already sources `target_stores.R`, so `simple_survival_store` is available in all pages
without further changes.

### Setup Block

```r
source("_setup.R")

km_os_data <- bind_rows(
  tar_read_raw("simple_survival_km_os_rvar_prior_re_arm",     store = simple_survival_store),
  tar_read_raw("simple_survival_km_os_rvar_posterior_re_arm", store = simple_survival_store)
)

quant_os_data <- bind_rows(
  tar_read_raw("simple_survival_quant_os_prior_re_arm",     store = simple_survival_store),
  tar_read_raw("simple_survival_quant_os_posterior_re_arm", store = simple_survival_store)
)

obs_os_km <- tar_read(pioneer_obs_os_km, store = pioneer_store) |>
  filter(btype == "ub") |>
  select(!quantiles) |>
  unnest(km_data)
```

### Callout Note

Explains the landmark design:
- Patients conditioned on surviving to Week 13 (Day 85, Cycle 4 Day 1)
- Event times rebased: t = 0 at Week 13
- First post-treatment PSA (Day 64+ window) added as covariate
- Only the 0→2 (direct death) transition is modelled; 0→1 progression disabled
- `re_arm` variant: arm-level random effects on the baseline hazard

## Data Available

| Target | Content |
|--------|---------|
| `simple_survival_km_os_rvar_{prior,posterior}_re_arm` | `sample_os_km_est`, `spop_os_km_est` rvars by trial × t |
| `simple_survival_quant_os_{prior,posterior}_re_arm` | `sample_os_quant`, `spop_os_quant` by trial × quantile |
| `pioneer_obs_os_km` (from `pioneer_store`) | Observed OS KM for overlay |

**Not available** (excluded from pipeline): `sample_os_n` / `spop_os_n` — survival
proportions at fixed timepoints are not generated by the 0→2-only model
(`n_pfs_n_timepoints = 0`). No at-risk proportions section.
